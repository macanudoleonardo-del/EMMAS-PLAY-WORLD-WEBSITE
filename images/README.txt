HOW TO SAVE
-----------
- Right-click each photo → Save As → into this folder.
- Name them EXACTLY: emma-hero.jpg  and  emma-graduation.jpg
  (all lowercase, .jpg extension, no spaces).
- If your file is a .png or .heic, either rename the extension to .jpg
  won't work — actually re-save/export it AS .jpg (JPEG). PNG is fine too
  if you also change the file name in index.html to match.
